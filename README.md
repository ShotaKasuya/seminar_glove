# seminar_glove

## ピン用途

0~4 左手
0. 親指
1. 人差し指
2. 中指
3. 薬指
4. 小指

5~9 右手
5. 親指
6. 人差し指
7. 中指
8. 薬指
9. 小指

## パケット構造

* hand
  * 0: 左
  * 1: 右
* finger
  * 0b001: 親指
  * 0b010: 人差し指
  * 0b011: 中指
  * 0b100: 薬指
  * 0b101: 小指
